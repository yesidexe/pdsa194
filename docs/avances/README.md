# Documentación personal del proyecto

Esta carpeta no es la documentación formal de patrones. Es una guía de estudio para entender el sistema de punta a punta y poder explicarlo oralmente.

| Documento | Para qué sirve |
|---|---|
| [00_mapa_del_proyecto.md](00_mapa_del_proyecto.md) | Qué es el sistema, cómo está organizado, qué hace cada archivo y cuál es el recorrido completo de un voto. |
| [10_los_patrones_en_simple.md](10_los_patrones_en_simple.md) | Los 12 patrones explicados con problemas de la vida real, ejemplos del proyecto y límites honestos. |
| [11_guion_de_exposicion.md](11_guion_de_exposicion.md) | Guion de 10–15 minutos, demostración paso a paso, preguntas probables y plan de contingencia. |

## Orden recomendado

1. Lee `00_mapa_del_proyecto.md` para tener el mapa mental.
2. Lee `10_los_patrones_en_simple.md` y practica la frase de un minuto de cada patrón.
3. Ensaya con `11_guion_de_exposicion.md` y la aplicación corriendo.

## Anexo técnico

Los archivos `01_patron_singleton.md` a `08_patron_flyweight_proxy_database.md` conservan el detalle técnico por patrón. Están limpios de referencias externas al proyecto, pero la guía principal para estudiar y exponer es la de los tres documentos de arriba.
